Backup

Baixe uma cópia dos produtos, lotes e movimentações em um arquivo JSON.

O arquivo é gerado somente para leitura: nenhum dado do sistema é alterado ou apagado. Guarde a cópia em um local seguro.

Por segurança, informe a senha administrativa para liberar o download.

Restaurar backup

Envie um arquivo JSON gerado por este sistema. Produtos, lotes e movimentações do arquivo serão criados com os IDs originais ou, se o ID já existir, atualizados com os dados do arquivo.

Nenhum registro é apagado. O que existe no sistema e não consta no arquivo permanece como está.

Informe a senha administrativa para liberar a restauração.
