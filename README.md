**Hortifruti Ponto Certo** é um sistema web desenvolvido para auxiliar no controle de estoque e no acompanhamento de perdas de um pequeno hortifruti.

O sistema permite cadastrar produtos, registrar entradas, saídas e descartes, acompanhar o histórico de movimentações e visualizar informações do estoque por meio de um dashboard. Também possui controle de lotes e validade, alertas de produtos próximos do vencimento, backup e restauração dos dados e recursos de segurança para operações administrativas.

O projeto foi desenvolvido como parte do **Tema Integrador III – Projeto de Sistemas**, utilizando **Java 21, Spring Boot, Spring Data JPA, Thymeleaf, H2 e PostgreSQL**.
